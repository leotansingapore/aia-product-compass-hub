# Cheat Sheets

Thirty-three one-page reference cards. Each one distils a single week or module of training into the highest-leverage frameworks, scripts, and numbers - the things worth screenshotting and re-reading before a live call, fact-find, or pitch.

> **How to use this collection:** open the cheat sheet for what you're about to do, not what you finished learning. Heading into a cold-call block tomorrow? Pull up [Appointment Setting](core-training/appointment-setting.md). Walking into a PWV meeting? Pull up [PWV](product-mastery/week-07.md). Stuck on an objection mid-pitch? Pull up [Next 60 - Week 9: The Close](next-60-days/week-09.md). The day files in each course teach the concepts; the cheat sheets put them under your thumb when it matters.

## Provenance + maintenance

All 33 cheat sheets were distilled from the full curriculum on 2026-05-18:
- First 60 Days - 60 day files across 10 weeks
- Next 60 Days - 60 day files across 10 weeks
- Product Mastery Track - 35 day files across 7 weeks (canonical source: `aia-product-sales/<product>/day-NN.md`)
- Core Training - 6 modules pulled from the live Supabase `products` table

**When the source changes, the cheat sheet drifts.** Re-distill the affected card by:
1. Reading the updated day files / module sections
2. Re-running the highest-leverage frameworks through the cheat-sheet template (`_TEMPLATE.md` in this folder)
3. Updating the relevant `Sources` wikilinks at the bottom of the cheat sheet

If a card hasn't been re-distilled in 3+ months and the source has changed substantively, mark it `status: stale` in the frontmatter so future-you knows.
