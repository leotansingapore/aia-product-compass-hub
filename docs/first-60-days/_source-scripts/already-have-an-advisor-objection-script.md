# "Already Have an Advisor" — Objection Script

**Category:** `objection-handling`  
**Audience:** `warm-market`  
**Role:** `consultant`  
**Tags:** texting-eq, objection-handling, warm-market, existing-advisor  

## Case Study — Aunt as Advisor

### Objection: "My aunt is my advisor, and I don't mix friends with financial matters"

**Prospect:**
> "My advisor is my aunt so I usually go to her. I have bad experiences with friends as advisors so I tend to stay away. Just being honest haha. If I ever need to approach someone else, I'll let you know."

**Response (Acknowledge → Common Ground → Different Perspective → Safety Valve):**

> "Something that my clients feedbacked to me was how they wanted an advisor that'll be there for them for the next 4-5 decades in the same life stage, while an older advisor can be a concurrent mentor at the same time."
>
> "Anyway, I'm really hoping we can have a super casual chat about this, so that moving forward I can communicate and advise my friends better in such a situation."

---

**Result:** Prospect replied "lemme give it some thought" — door stayed open.

**Key takeaway:** You can have TWO advisors. Position the younger advisor as relatable, the existing one as a mentor. Don't try to replace — complement.
