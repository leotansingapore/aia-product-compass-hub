# Video Courses — Master Index (Next 60 Days)

This is the entry point for **all transcribed video courses** that supplement the Next 60 Days curriculum. Each course lives in its own subfolder under `first-60-days/_source-supplementary/` (shared resource), with: per-video markdown files (lecture notes + raw transcript), a README, and a manifest.json.

11 courses, 200+ videos, ~7 MB of source material — all retrievable, all mapped to specific Next 60 Days curriculum days.

> **Why these live under `first-60-days/_source-supplementary/`:** the same video courses serve both curricula. First 60 Days uses them as foundational onboarding material; Next 60 Days uses them for advanced sales mechanics, pitch crafting, closing, and product mastery. This index reframes the catalog with a Next 60 Days lens — the [first-60-days INDEX](../../first-60-days/_source-supplementary/INDEX-VIDEO-COURSES.md) reframes the same catalog for new FCs.

## How to use this index

### When you're working on a specific day

1. Read the day file in [next-60-days/week-N/day-XX.md](../week-1/)
2. Look up the day in the mapping table above
3. Pull the highest-leverage videos for that day's topic from the matching course's README

### When you're answering a topic question (no specific day)

1. Identify the domain (sales mechanics → General Flow; CI product → UCC; protection → HSGM/PLP/GPP; ILP → APA; CPF → Basic CPF)
2. Open that course's README for the highest-leverage video shortlist
3. Read the lecture notes first (clean markdown), then drop into the raw transcript for verbatim phrasings if needed

### When teaching the curriculum

Use the courses as **source material**, not lessons. The day files in [week-1/](../week-1/) through [week-10/](../week-10/) are the lessons. Courses provide:
- Verbatim phrasings advisors actually use ("how would I say this in real life?")
- Field anecdotes you can substitute into examples
- Specific numbers (premiums, payouts, fees) cited to a video the agent can pull

## Cross-course relationships

Several recurring patterns the index calls out so an agent can chain courses:

- **General Flow 6-phase ↔ PWV 7-phase variant** — General Flow is the generalist baseline; PWV is the pre-retiree-specific expansion. Use General Flow for generic prospects, PWV when prospect is 50-65 with retirement as primary frame.
- **HSGM → APA cross-sell** — Healthcare cost projections (HSGM video 30 specifically) become the door-opener for APA accumulation. The "protection floor first, accumulation second" sequence.
- **APA → PWV product sequence** — APA for accumulation phase; convert to PWV near retirement. Pre-retiree restructures often move legacy ILPs into APA, then into PWV.
- **Basic CPF Knowledge ↔ PWV CPF videos (35-37)** — Basic CPF is technical mastery; PWV videos 35-37 are the sales delivery of the same content inside a meeting flow.
- **GoalsMapper ↔ PWV Retirement Funding Calculator** — Two different presentation tools for the Phase-2 plan-building moment. GoalsMapper for generalist; PWV calc for pre-retirees.

## Provenance

All transcripts pulled from the live `training_videos` JSON in the AIA Product Compass Hub Supabase database (`aia-product-compass-hub` repo, table `products`). Original transcription via tactiq.io (YouTube). Lecture-note `rich_content` was generated alongside the transcripts in the hub admin tool.

When the source data changes (new videos added, transcripts updated), regenerate the affected course folder by re-running the matching `gen_*_supplementary.py` script in `/tmp/`. Each course's `manifest.json` records the chars-per-video so you can compare against the live database to detect drift.
