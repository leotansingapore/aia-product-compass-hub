# Canned Sales Tracks — Index

> **A canned sales track is a word-for-word meeting script** — memorized until it sounds natural. Not a cage; a scaffold. It handles the routine 80% so you can improvise on the meaningful 20%.

> **The meta-rule (from Market Survey): "Memorise → Internalise → Naturalise."** Read from the page = lose rapport instantly.

This file is an **index**. The actual track contents are too long for one article — they live in the `_reference/` playbooks. Use this file to find the right track for your next meeting.

---

## 1. Warm-Market Flow (Primary Canned Track)

**Location:** [`_reference/warm-market-flow-full-playbook.md`](_reference/warm-market-flow-full-playbook.md) — 7 videos, 97 KB.

**The track covers:**
- **Total Wealth Concept (TWC)** — human capital vs financial capital (the Golden Goose frame)
- **4 Pillars of Risk Management** — Hospitalisation, Accident, Critical Illness, Death/Disability
- **10–15% income rule** for insurance budget
- **3-thirds model** (short-term / medium-term / long-term savings)
- **Progressive disclosure** — don't present all 4 pillars in meeting 1; follow the client's stated priority
- **Cross-sell bridges** — each product naturally leads to the next
- **ABCD Four Promises** delivery (Assurance / Best Interest / Confidentiality / Disclosure)
- **Financial Health Review (FHR) close**

**When to use:** warm-market prospects, value-first first meeting, no immediate product push.

**Pairs with:** [[market-survey-warm-market]] (pre-track phone appointment) → this track (the meeting) → [[art-framework-and-objection-techniques]] (handle objections that arise).

## 2. General Flow (Old / New / Supplementary)

**Location:** [`_reference/general-flow-full-playbook.md`](_reference/general-flow-full-playbook.md) — 29 videos, 292 KB.

**Structure:**
- **Old Version** (13 videos) — legacy flow; archived for reference
- **New Version** (9 videos) — **current primary** track
- **Supplementary Training** (7 videos) — edge cases + advanced moves

**Coverage (New Version):**
- Opening: intent + value statement
- Fact-finding: current situation → insurance coverage → investment status
- Concept presentation (integrated with education)
- Objection handling (within the flow)
- Close + referral ask

**When to use:** any audience — this is the generic backbone when the warm-market-flow isn't a fit.

**Teaching priority:** always use New Version. Old Version is reference only.
