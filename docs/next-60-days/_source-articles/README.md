## How to use this folder

**Building day files:** consume from the tight articles. Reference the `_reference/` files only when you need the full verbatim content or a specific script.

**Adding a new source article:** keep it tight. Include frontmatter: `status`, `course`, `suggested_week`, `suggested_day`, `primary_slots`, `related_frameworks`, `tags`. See any existing tight file for the template.

**Cross-links:** files use `[[wikilink]]` syntax. Obsidian resolves by filename across the whole vault — folder structure is safe.
