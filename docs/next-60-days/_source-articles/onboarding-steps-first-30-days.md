# Onboarding Steps — First 30 Days (Leo's operational onboarding)

**What this is.** The hands-on tactical onboarding Leo ships to newly-RNF'ed AIA consultants inside `aia-product-compass-hub`. It covers everything the Next 60 Days curriculum does **not** cover: income/commission structure, tool access (Lark, CRM, activity tracker), business-plan docs, vision board, pledge sheet, plus tactical daily-prospecting setup (phones, SMA checklist, ad access). The Next 60 Days module teaches *how to sell*; this covers *how to operate the business*.

**Target learner.** Consultant who has passed RES5 and submitted the RNF application. 30-day window. 6 hours/day recommended split: 2 hrs Income Structure + Business Planning (first 7 days), then 2 hrs Familiarity + 2 hrs Prospecting in parallel.

**End state after 30 days:**
1. Know where to access every resource needed to operate
2. Familiar with the products they'll be selling
3. Warm prospecting kicked off (cases teed up for contract start)

---

## 1. Introduction (overview)

For consultants post-RES5 + post-RNF-submission. 30-day window to uncover blind spots across income structure, tool access, and prospecting setup.

Daily split (block 6 hrs/day):
- **Days 1–7:** 2 hrs → Income Structure + Business Planning modules. After Day 7 the 2 hrs reallocates to roleplay feedback or extra prospecting.
- **Parallel from Day 1:** 4 hrs/day → 2 hrs Familiarity + 2 hrs Prospecting.

## 3. Business Planning

### 3a. Tech Stack Access

**Lark setup:**
1. [Join Lark "100% MDRT Team"](https://nsgukkz32942.sg.larksuite.com/invite/2475o5zzfclg1?join=1&team_name=100%25+MDRT+Team) — invite code `WPMMPELG`.
2. Set up Lark **Desktop** so docs open in the nav bar.
3. Install Lark **Mobile**.
4. Open and pin [the access-checklist doc](https://nsgukkz32942.sg.larksuite.com/wiki/Jqu5wln6eiVL7PklkgplPQc4gIe) to your left sidebar.
5. Get access to every resource listed there.
   - URLs → create a Chrome folder.
   - Lark bases/docs → pin to left sidebar.
   - Just secure access now; content walkthroughs happen on coaching calls/1-1s.

**Task list (GTD-style):**
1. Create a Lark task list with sections (ad-hoc + recurring).
2. 15-min "brain scan" — dump everything into it.
3. Multiple task lists are fine (school, personal, etc.).
4. Watch [this GTD YouTube intro](https://www.youtube.com/watch?v=7M6bIeVbCqA). Automatic habit: the moment you have an idea/need, key it in.
5. "Create task from message" habit: every important Lark message becomes a task. **Capture** constantly; **process** in a focused session each day.
6. Optional deeper dive: [Lark official 2-min task guide](https://youtu.be/HtBTAnWH3vk).

**CRM (Lark Base):**
1. Ask Leo to spin up your CRM. Access [here](https://nsgukkz32942.sg.larksuite.com/base/AKOwbIgCJajwpdsZxtmluiF7gZd?table=tblK1Q35uvwAe4pU&view=vew7AogXqL).
2. While waiting, watch [Lark Base intro](https://youtu.be/KH2h4kxc_4c).
3. Then watch the [CRM Loom tutorials](https://nsgukkz32942.sg.larksuite.com/wiki/KwYfw7WRxiH6pskbm2tlHCOXgie).
4. Habit: sort every lead by stage.

7. Post every upcoming friend-meeting to the onboarding GC for portfolio support.

### 4b. Prospecting (Daily)
[Loom tutorial](https://www.loom.com/share/744a0b57822a464dbf6f98301ef1b6fb)

Also read the full appointment-setting module (1–2 hrs): [Skool classroom](https://www.skool.com/finternship/classroom/411f0212).

**Objective (end of setup):**
1. Buy a new number, set up on **WhatsApp Business** on the same phone.
2. Ideally a second phone — dial with 2 numbers simultaneously (doubles cold-call throughput).
3. Access + pin [the prospecting doc](https://nsgukkz32942.sg.larksuite.com/wiki/OTW3wipXSi0y8nkU5l3llk3Vgrb) to Lark left sidebar.
4. Block **2–3 hrs/day** on the calendar for prospecting — cold calling (cold leads + SMA leads) or [warm outreach](https://www.skool.com/finternship/classroom/8de2c1c8).
   - Warm outreach minimum: 3–4 friend meetings per week (policy checks, GoalsMapper demos, policy-summary offers). Critical for pre-EPS consultants.
5. 1-1 with Leo on scripts (calling + texting).
6. Ask Leo for cold leads — **unlimited cold leads** for your first 3 months.
7. Complete the [SMA checklist](https://nsgukkz32942.sg.larksuite.com/wiki/WZiRwAtHgipbzfklv0ClplaMgzb) before running any ads.
8. Log numbers daily on [the activity tracker](https://track.themoneybees.co/dashboard).
9. Facebook lead-gen unlocks post-RNF.

**Deadline:** all of the above within 7 days — kickstart prospecting **before** RNF.
